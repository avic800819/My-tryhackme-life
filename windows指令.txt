一、 檔案搜尋與內容過濾 (CMD / PowerShell)
--------------------------------------------------------------------------------
指令/參數              原始英文完整單字            白話功能與設計邏輯
--------------------------------------------------------------------------------
dir                   directory                   列出當前目錄內容
  - /s                subdirectories              遞迴搜尋子目錄：往下遍歷所有層級資料夾
  - /b                bare format                 極簡裸模式：僅印出完整檔案路徑，方便複製過濾
  - /a:h              attribute: hidden           屬性過濾：只列出具備隱藏屬性的檔案與資料夾

findstr               find string                 文字搜尋工具（類似 Linux grep）
  - /s                subdirectories              在目前目錄及所有子目錄的檔案中進行搜尋
  - /i                ignore case                 忽略大小寫：不分大小寫比對字串
  - /n                number                      顯示行號：輸出符合字串所在檔案中的行號

where                 where                       搜尋執行檔路徑（類似 Linux which）
  - /R                recurse                     遞迴指定路徑：指定從特定根目錄往下搜尋符合的檔案

tree                  directory tree              以樹狀圖顯示目錄結構
  - /F                files                       展開檔案：除了資料夾外，連同裡面的檔案一併列出
  - /A                ASCII                       純字元模式：改用標準 ASCII 字元繪製樹狀圖，防止終端機亂碼

Get-ChildItem         Get Child Item              PowerShell 檔案與目錄列舉 cmdlet
  - -Recurse          Recurse                     遞迴遍歷子目錄
  - -Filter           Filter                      指定檔案比對條件（如 *.log, *.txt）
  - -ErrorAction      Error Action                設定錯誤處理策略（搭配 SilentlyContinue 可忽略權限錯誤）

Select-String         Select String               PowerShell 文字內容搜尋 cmdlet（支援正規表達式）
  - -Pattern          Pattern                     指定欲比對搜尋的字串規則或樣式
  - -Path             Path                        指定要進行內容搜尋的檔案路徑


dir "C:\Users\*waldo.txt*" /s /b 2>nul            使用 dir 遞迴模糊搜尋


findstr /s /i /n "password" C:\Users\*.txt 2>nul    搜尋檔案內文關鍵字（findstr）


Get-ChildItem -Path C:\Users -Filter "*waldo*" -Recurse -File -ErrorAction SilentlyContinue | Select-Object FullName    安全遞迴搜尋（自動略過無權限目錄）：

Get-ChildItem -Path C:\Users -Filter "*waldo.txt*" -Recurse -File -ErrorAction SilentlyContinue | Get-Content    搜尋並直接讀取內容（管線串接）：



檢視目前身分與檔案權限

whoami /groups
whoami /priv                                      確認當前帳號是否擁有管理員權限（如具有 Administrators 或 SeTakeOwnershipPrivilege）：


icacls "C:\Users\TargetFolder"                        檢查目標目錄/檔案目前的存取控制清單（ACL）：

takeown /f "C:\Users\TargetFolder" /r /d y                將目標目錄及其所有子檔案的擁有人強制改為當前登入者：

icacls "C:\Users\TargetFolder" /grant administrators:F /t       取回擁有權後，為管理員群組或自己加上完全存取權限（Full Access）：

type "C:\Users\TargetFolder\file.txt"                            權限修復完成後，直接檢視內容：

--------------------------------------------------------------------------------
whoami                who am I                    檢視當前已登入或取得 Shell 的使用者帳號

  - /groups           groups                      群組清單：檢視當前帳號隸屬的所有安全性群組
  - /all              all                         完整傾印：一次輸出帳號 SID、隸屬群組及所有 Token 特權狀態

wmic os list brief    wmic os list brief          列印作業系統簡要資訊（快速取得組建版本號 BuildNumber 與註冊使用者）
systeminfo            system information          印出完整系統資訊、Hotfix 修補清單與硬體架構（速度較慢）

Get-Location                                      確定位子(資料夾)

三、 系統與網路環境枚舉 (Host & Network)
--------------------------------------------------------------------------------
指令/參數              原始英文完整單字            白話功能與設計邏輯
--------------------------------------------------------------------------------
systeminfo            system information          印出作業系統名稱、核心版本號、Hotfix 修補清單與硬體架構
route print           route print                 印出本機路由表與介面清單
ipconfig /all         IP configuration all        完整列出所有網路卡之 IP、子網路遮罩、Gateway 與 DNS

netstat               network statistics          監控本機所有 TCP/UDP 網路通訊協定與連接埠狀態
  - -a                all                         所有連線：顯示所有已連線以及正在 Listening 的連接埠
  - -n                numerical                   數字顯示：不進行反向 DNS 解析，直接顯示 IP:Port，速度最快
  - -o                owning process ID           顯示 PID：顯示佔用該連接埠的程序識別碼，方便後續追查

tasklist              task list                   列出目前系統正在執行的所有前景與背景程序
  - /v                verbose                     詳細資訊：顯示執行程序的執行身分（User Name）與視窗標題
  - /svc              services                    關聯服務：顯示各個 svchost.exe 內載入的 Windows 服務名稱

================================================================================
【Windows 指令速查補充：使用者列舉、啟動項與註冊表探查】
================================================================================

一、 使用者帳號與 SID 列舉 (User & SID Enumeration)
--------------------------------------------------------------------------------
‧ 查目前登入者身分與 SID：
  whoami /user

‧ 查詢本機所有使用者的名稱與 SID (CMD / WMIC 快速版)：
  wmic useraccount get name,sid

‧ 查詢指定使用者的 SID (CMD / WMIC)：
  wmic useraccount where name='bob.smith' get name,sid

‧ 查詢指定使用者與 SID (PowerShell 物件篩選)：
  Get-CimInstance Win32_UserAccount -Filter "Name = 'bob.smith'" | Select-Object Name, SID

‧ 列出所有本機帳號清單 (CMD 原生)：
  net user


二、 開機自啟動與停用項目探查 (Startup & Disabled Programs)
--------------------------------------------------------------------------------
‧ 列出系統所有開機自啟動程式清單 (名稱、執行指令、註冊路徑)：
  Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location, User

‧ 檢查「工作管理員」中被使用者停用 (Disable) 的開機自啟程式 (檢查登錄表)：
  Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run"

‧ 查詢本機已安裝的第三方防毒軟體 (AntiVirus Product)：
  wmic /namespace:\\root\securitycenter2 path antivirusproduct get displayname


三、 PowerShell 物件篩選與管線核心語法 (Object Pipeline)
--------------------------------------------------------------------------------
‧ 挑選特定屬性欄位顯示 (類似 Linux awk，但按屬性名挑選)：
  [指令] | Select-Object Name, SID, PathName

‧ 條件篩選 (類似 Linux grep)：
  [指令] | Where-Object { $_.Name -like "*關鍵字*" }

‧ 條列展開詳細資訊 (不縮排截斷長文字)：
  [指令] | Format-List

(Get-CimInstance Win32_Group -Filter "Name = 'HR'").SID

# CMD / WMIC 方式查詢
wmic useraccount where name='Jim' get sid
wmic group where name='HR' get sid

Get-Service | Where-Object { $_.DisplayName -like "*update*" -or $_.Name -like "*update*" } | Select-Object Name, DisplayName

Get-CimInstance Win32_Service -Filter "Name = 'wuauserv'" | Select-Object Name, DisplayName, State, PathName | Format-List

================================================================================
PowerShell vs Linux 常用指令速查對照表 (HTB Windows Command Line)
================================================================================

[檔案與目錄搜尋]
--------------------------------------------------------------------------------
PowerShell 指令 : Get-ChildItem
常用別名/簡寫   : gci, ls, dir
Linux 對應      : ls / find
功能說明        : 列出目錄與檔案內容

PowerShell 參數 : -Recurse
Linux 對應      : -r / -R
功能說明        : 遞迴搜尋目前目錄及其底下的所有子目錄

PowerShell 參數 : -File
Linux 對應      : -type f
功能說明        : 僅篩選出「檔案」（排除資料夾）


[文字與字串搜尋]
--------------------------------------------------------------------------------
PowerShell 指令 : Select-String
常用別名/簡寫   : sls
Linux 對應      : grep
功能說明        : 在檔案或輸出文字中搜尋指定字串或正則表達式


[管線與資料過濾]
--------------------------------------------------------------------------------
PowerShell 符號 : |
Linux 對應      : | (Pipe)
功能說明        : 將前一個命令的輸出當作下一個命令的輸入傳遞

PowerShell 指令 : Where-Object
常用別名/簡寫   : where, ?
Linux 對應      : grep / awk
功能說明        : 依特定條件過濾物件屬性值 (如: where {$_.Name -like "*.txt"})

PowerShell 指令 : Select-Object
常用別名/簡寫   : select
Linux 對應      : awk '{print $x}' / cut
功能說明        : 挑選指定的物件欄位（屬性）顯示 (如: select Name, Length)


[資料統計與排序]
--------------------------------------------------------------------------------
PowerShell 指令 : Sort-Object
常用別名/簡寫   : sort
Linux 對應      : sort
功能說明        : 將結果依照指定欄位或字母順序排序

PowerShell 指令 : Get-Unique
常用別名/簡寫   : unique
Linux 對應      : uniq
功能說明        : 去除重複項目（通常先接排序）

PowerShell 指令 : Measure-Object
常用別名/簡寫   : measure
Linux 對應      : wc -l / wc
功能說明        : 統計物件數量、行數或數值加總


[物件結構查看]
--------------------------------------------------------------------------------
PowerShell 指令 : Get-Member
常用別名/簡寫   : gm
Linux 對應      : 無直接對應 (物件反射)
功能說明        :
