一、 系統基礎移動與翻找 (Linux 基礎導航)
------------------------------------------------------------------------------------------------------------------------
指令/參數     原始英文完整單字                     白話功能與設計邏輯
------------------------------------------------------------------------------------------------------------------------
ls            list                                列出目錄裡的檔案與資料夾
  -l          long (listing format)               詳細格式（直列排列，顯示擁有者、檔案大小、修改日期與權限）
  -a          all                                 顯示全部（包含開頭為 . 的隱藏檔案）
  -h          human-readable                      人類易讀格式（將檔案大小以 K、M、G 顯示，而非純 Byte 數字）
cd            change directory                    切換當前工作目錄
pwd           print working directory             印出目前所在的工作目錄完整路徑
cat           concatenate                         本意為串接檔案，常用於直接將檔案內容印在螢幕上
grep          globally search for regular         在檔案內搜尋符合正規表達式的字串，並把該行印出
              expression and print
  -i          ignore-case                         搜尋時忽略英文大小寫差異
  -r / -R     recursive                           遞迴搜尋（連同所有子資料夾深層尋找）
  -v          invert-match                        反向選取（只印出「不包含」該關鍵字的所有行）
mkdir         make directory                      建立新的資料夾
  -p          parents                             建立多層目錄時，若上層目錄不存在則自動補建
rm            remove                              刪除檔案或資料夾
  -r          recursive                           遞迴刪除（刪除整個資料夾及其內部所有檔案）

cp            copy                                複製檔案或資料夾
mv            move                                移動檔案（亦用作檔案重新命名）
echo $...     echo                                印路徑(字) 看變數內容
uname -a      all name                            顯示各項硬體及軟體 os 各項系統
ps            ps                                  看工作管理員執行甚麼程式
ip a          address                             看網卡的ip位置
 -t           time                                查詢時間
ls -i         inode                               列出索引(inode)號碼
| wc -l                                           計算數量 後面固定結尾 顯示數量
dpkg          控制台                              打開控制台(新增移除程式)
|             交                                  把計算結果給下一個人 
^             過濾工具                            過濾工具
grep          文字過濾                            Ctrl + F
netstat       網路                                網路統計
 -tuln        查網路門牌                          查網路門牌
ps aux        翻工作管理員                        翻工作管理員把所有程式吐出來
-m            建立家目錄                          建立家目錄
--lock        鎖定使用者                          鎖定使用者
su            切換使用者                          切換使用者
command       命令/指令                           我命令他 不切換過去
 



二、 權限、身分與提權 (Privilege Escalation)
------------------------------------------------------------------------------------------------------------------------
指令/參數     原始英文完整單字                     白話功能與設計邏輯
------------------------------------------------------------------------------------------------------------------------
whoami        who am i                            印出目前連線/登入的使用者帳號名稱
sudo          superuser do                        以超級管理員（root）身分執行指定指令
  -l          list                                列出當前帳號可免密碼或特殊執行的 sudo 權限清單
su            switch user                         切換至其他使用者（未帶參數時預設切換至 root）
chmod         change mode                         變更檔案的存取模式與讀寫執行權限
  +x          executable                          賦予執行權限（常用於木馬或提權腳本）
chown         change owner                        變更檔案或資料夾的擁有者與所屬群組
find          find                                系統檔案深度搜尋工具
  -perm       permission                          依權限篩選檔案（常搭配 -u=s 搜尋 SUID 提權後門）
  -type f     type file                           指定只搜尋一般檔案（排除資料夾）
  2>/dev/null 2 (stderr) redirect to null         將所有錯誤警告與存取拒絕訊息重定向丟入黑洞，防止洗版
which                                             找尋檔名的絕對路徑(可執行程式) 二進位檔
-size +25k -size -28k size                    依檔案大小篩選（+代表大於，-代表小於，k代表KB）




三、 網路偵察掃描 (Nmap - Network Mapper)
------------------------------------------------------------------------------------------------------------------------
指令/參數     原始英文完整單字                     白話功能與設計邏輯
------------------------------------------------------------------------------------------------------------------------
-s            scan                                指定掃描類型（Scan）的前置字首
  -sC         script (Common / default)           啟用 Nmap 預設常見的 NSE 弱點與資訊枚舉腳本
  -sV         service Version                     探測目標端口上運行的軟體名稱與版本號
  -sS         SYN Scan                            半開放隱蔽掃描（只發送 TCP SYN 握手包，速度快且不易被記錄）
  -sT         socket / TCP Connect Scan           建立完整的 TCP 三向交握連線（無 root 權限時的掃描模式）
  -sU         scan UDP                            針對 UDP 通訊協定進行專用探測（如 DNS、SNMP）
-p            port                                指定欲掃描的連接埠編號
  -p-         port all (1-65535)                  連字號代表全範圍，掃描 1 到 65535 全部連接埠
-T            Timing template                     設定掃描速率模板（-T0 龜速 ~ -T5 狂暴，一般打靶推薦 -T4）
-o            output                              指定掃描結果報告的輸出格式
  -oN         output Normal                       輸出為人類易讀的標準純文字格式
  -oG         output Grepable                     輸出為單行格式，方便配合 grep 指令快速篩選
  -oA         output All                          一次輸出 Normal、XML、Grepable 三種格式報告
-A            Aggressive                          強力綜合探測（整合 OS 偵測、版本偵測、腳本掃描與路由追蹤）


四、 網頁目錄爆破 (Gobuster)
------------------------------------------------------------------------------------------------------------------------
指令/參數     原始英文完整單字                     白話功能與設計邏輯
------------------------------------------------------------------------------------------------------------------------
dir           directory / file enumeration        指定操作模式為目錄與檔案暴力枚舉
-u            url                                 指定目標網站的完整網址（URL）
-w            wordlist                            指定進行比對測試的字典檔案路徑
-x            extensions                          指定嘗試探測的副檔名清單（例如 php,txt,html）
-t            threads                             設定發送請求的並發執行緒數量（增加速度）
-k            insec-k-ure (skip SSL)              略過 SSL/TLS 憑證無效或過期的安全性警告，繼續測試


五、 網路連線與後門監聽 (Netcat - nc)
------------------------------------------------------------------------------------------------------------------------
指令/參數     原始英文完整單字                     白話功能與設計邏輯
------------------------------------------------------------------------------------------------------------------------
-l            listen                              開啟監聽模式（等待外部連線，做為接收端）
-v            verbose                             顯示詳細連線日誌與傳輸狀態，非無聲模式
-n            numeric-only IP                     僅使用數字 IP，略過 DNS 網域名稱反查以加快連線
-p            port                                指定監聽或連線的本機/遠端連接埠號
-e            execute                             連線建立成功後自動啟動並交出控制權的程式（如 /bin/bash）


六、 服務密碼暴力破解 (Hydra)
------------------------------------------------------------------------------------------------------------------------
指令/參數     原始英文完整單字                     白話功能與設計邏輯
------------------------------------------------------------------------------------------------------------------------
-l            login (lowercase)                   小寫表示指定「單一」已知的登入使用者帳號
-L            Login list (UPPERCASE)              大寫表示指定包含「大量帳號名單」的文字字典檔
-p            password (lowercase)                小寫表示指定「單一」特定的測試密碼
-P            Password list (UPPERCASE)           大寫表示指定包含「密碼字典庫」的文字檔案（如 rockyou.txt）
-s            service port                        指定非標準服務端口（如目標將 SSH 開在 2222）
-V / -vV      verbose / Very Verbose              終端機即時印出目前正在嘗試的每一組帳號密碼配對過程

========================================================================================================================
參數規律口訣：
1. 小寫參數通常代表單一值（-l 指定單一帳號、-p 指定單一密碼/端口）。
2. 大寫參數通常代表字典清單（-L 帳號字典、-P 密碼字典）。
3. 字母 v（verbose）在 90% 以上的工具中均代表「話很多、印出詳細過程」。
