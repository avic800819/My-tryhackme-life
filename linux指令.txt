十、 Linux 指令的文法結構與邏輯連接詞 (CLI Grammar & Operators)
========================================================================================================================

1. 指令句型文法（主詞/動詞 -> 副詞/開關 -> 受詞/目標）
------------------------------------------------------------------------------------------------------------------------
Linux 指令就像在跟一個按劇本演戲的工具人說話：
[工具本體 / 動詞]       [參數開關 / 調整細節]       [目標對象 / 數值 / 受詞]
http-server            -p                        8080
nmap                   -sV                       10.10.10.1
nc                     -lvnp                     4444
cat                    -n                        /etc/passwd

* 避坑提醒：
  終端機永遠要先給「工具名稱」（主詞/動詞）。
  只輸入「-p 8080」等於進餐廳對空氣喊「小辣」，店員不知道你要吃排骨飯還是牛肉麵。


2. Linux 的連接詞（AND / OR / 依序執行）
------------------------------------------------------------------------------------------------------------------------
符號語法       英文對應 / 概念                      運作邏輯與使用情境
------------------------------------------------------------------------------------------------------------------------
&&             AND (而且 / 條件成功)               【前一個指令執行成功 (Exit Code 0)，才接著做下一個】
                                                   實戰：更新套件並安裝 -> apt update && apt upgrade -y
                                                   打靶：切進目錄成功才開工 -> cd /tmp && ./exploit.sh

||             OR (或者 / 失敗補救)                【前一個指令執行失敗，才跳去執行下一個做備案】
                                                   實戰：ping 失敗就警告 -> ping -c 1 10.10.10.1 || echo "主機已離線"

;              Semicolon (依序執行)                【不管前一個指令成功還是失敗，按順序一路做下去】
                                                   實戰：建立資料夾並切換 -> mkdir test ; cd test

|              Pipe (管線接力棒)                   【把前一個指令產生的文字內容，直接倒給下一個工具加工】
                                                   實戰：過濾服務行程 -> ps aux | grep http
                                                   計算行數 -> cat /etc/passwd | wc -l

十一、 Linux 檔案類型與磁碟分區 (File Types & Partitions)
========================================================================================================================
1. 三大核心檔案類型
   - 普通文件 (Regular File, 標記 -)：等同 Windows 的一般檔案 (.txt, .exe, .jpg)。
   - 目錄 (Directory, 標記 d)       ：等同 Windows 的資料夾 (Folder)。
   - 符號連結 (Symlink, 標記 l)     ：等同 Windows 的捷徑 (.lnk)，指向另一個檔案或路徑。

2. 磁碟分區與檢視指令
   - Windows 叫 C槽、D槽；Linux 統一掛載在根目錄 (/) 樹狀結構下。
   - lsblk (list block devices)    ：列出所有磁碟與分區結構（如 sda 包含 sda1, sda2, sda3）。
   - df -h (disk free human-readable)：檢視每個分區的掛載點與剩餘容量空間。

【Bash 實務速查：輸入輸出與比對】
==================================================

1. 變數存取鐵律：
   - 存入/賦值（不加 $）：var="內容"
   - 取出/使用（一定要加 $）：echo $var

2. 重要語法：
   - 執行指令並存回：var=$(echo $var | base64)
   - 算字串總長度：${#var}  （範例：[ "${#var}" -gt 113450 ] 判斷是否大於）
   - 比對文字包含：[[ "$var" == *"$value"* ]]  （前後加星號代表包含）
   - 只抓末端字元：echo "$var" | tail -c 20

3. 輸出雙向分流（tee）：
   - 指令 | tee -a 檔名.txt
   - 效果：螢幕看得到進度，同時自動寫入存檔（-a 代表不覆蓋、接續寫在後面）。

【Bash 實戰重點與易混淆觀念整理】
==================================================

1. 三大常見字元/字串工具區分（不要搞混）：
   - -gt       ：條件判斷的大於（Greater Than），只能放在 [ ] 或 [[ ]] 裡面比數字大小
   - tail -c 20：截斷剪刀，只印出最後面的 20 個字元（Bytes）
   - wc -c     ：計數磅秤，量整串文字的總長度/字元數（例如：echo $var | wc -c）

2. 連續 Base64 與長度坑點：
   - 迴圈覆蓋寫法：
     for i in {1..28}
     do
         var=$(echo $var | base64)
     done
   - 長度差異：
     * ${#var} 算純字元數
     * echo $var | wc -c 會把結尾的換行符號（\n）一起算進去（HTB 解密題差 1 就會 bad decrypt，常需用 wc -c）

3. Function（函式）的本質：
   - 定義時只備用不執行：
     function decrypt {
         # 放一堆複雜指令，例如 openssl 解密
     }
   - 主流程隨傳隨到：
     只要在下方打出「decrypt」，程式就會跳去執行那一整包內容。

【Bash 實務使用時機速查】
==================================================

1. 查系統日誌（Log 分析與排錯）：
   - tail -n 50 檔名   ：快速看最新噴出的 50 行錯誤，不用打開整個肥大的檔案
   - tail -c 20        ：只抓末端特定字元（如抓特定的金鑰、代碼後綴）
   - grep "關鍵字" 檔名 | wc -l ：一秒算出某個錯誤或特定事件出現了幾次

2. 資料清理與格式驗證：
   - 檢查長度（wc -c 或 ${#var}）：比對身分證、統編、卡號長度是否少一碼或格式異常
   - 門檻判斷（-gt）：數值比大小（例如：當連線錯誤次數超過 10 次時發出警報）

3. 自動化與定期排程：
   - for / while 迴圈  ：連續測試網路連線、批次改名大量檔案、限制重試次數
   - function（函式）  ：把「寄信通知」、「清理暫存」、「寫入日誌」寫成獨立積木，隨傳隨到不用重複貼程式碼

【Bash 函式進階：參數傳遞與回傳狀態】
==================================================

1. 函式帶參數進去（用順序 $1, $2 接收）：
   function scan {
       echo "正在掃描目標 IP: $1，目標 Port: $2"
   }
   # 呼叫方式：
   scan 192.168.1.1 80

2. 執行狀態碼（$? 判斷上一步成不成功）：
   - 0     ：代表成功、完全正常
   - 非 0  ：代表失敗或報錯（例如 1、127 找不到指令）
   - 查詢上個指令是否成功：echo $?
   - 實務用法（成功才繼續）：
     ping -c 1 10.10.10.1 > /dev/null
     if [ $? -eq 0 ]; then
         echo "目標活著！"
     fi
