================================================================================
Windows 註冊表 (Registry) 核心速查筆記 (HTB & 滲透測試實務)
================================================================================

[核心觀念]
--------------------------------------------------------------------------------
1. 本質：Windows 的全域核心設定資料庫。
2. 結構對照：
   - Key (機碼)     = 資料夾
   - Value (值/數值) = 該資料夾底下的設定變數與資料內容
3. 最常接觸的兩大根路徑：
   - HKLM (HKEY_LOCAL_MACHINE) : 整台電腦、所有使用者的全域設定 (需管理員權限)
   - HKCU (HKEY_CURRENT_USER)  : 當前登入使用者的專屬設定 (一般使用者權限即可改)


[滲透測試的兩大實戰用途]
--------------------------------------------------------------------------------
1. 權限維持 / 留後門 (Persistence)：
   - 目的：讓木馬/後門在目標「重開機」或「使用者登入」時自動執行。
   - 經典自動啟動機碼路徑：
     HKCU\Software\Microsoft\Windows\CurrentVersion\Run
     HKLM\Software\Microsoft\Windows\CurrentVersion\Run
     HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce

2. 敏感資訊挖掘 (Credential Hunting / Privilege Escalation)：
   - 目的：搜尋註冊表內是否殘留管理員明文密碼、自動登入密碼 (AutoLogon)、VNC 密碼等。


[實務最常用指令 (建議直接用 reg.exe，簡短好記)]
--------------------------------------------------------------------------------
1. 查詢某個機碼底下的設定：
   reg query "HKLM\Software\Microsoft\Windows\CurrentVersion\Run"

2. 在註冊表內全域搜尋包含「password」關鍵字的機碼與數值：
   reg query HKCU /f "password" /t REG_SZ /s /k
   (參數說明：/f 關鍵字, /t 類型, /s 遞迴所有子項目, /k 搜尋機碼名)

3. 寫入開機自動啟動後門 (以 RunOnce 為例)：
   reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce" /v "MyBackdoor" /t REG_SZ /d "C:\Users\Public\payload.exe"
   (參數說明：/v 數值名稱, /d 執行檔路徑)

4. 刪除該後門機碼：
   reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce" /v "MyBackdoor" /f


[PowerShell 語法對照 (HTB 題目常考，看懂即可)]
--------------------------------------------------------------------------------
- 查數值內容 : Get-ItemProperty -Path "Registry::HKLM\Software\..."
- 新增機碼   : New-Item -Path "HKCU:\Software\..." -Name "NewKey"
- 設定數值   : Set-ItemProperty -Path "..." -Name "名稱" -Value "內容"
- 刪除數值   : Remove-ItemProperty -Path "..." -Name "名稱"

================================================================================
Windows 事件日誌 (Event Logs) 核心速查筆記 (HTB & 資安防禦鑑識)
================================================================================

[核心觀念]
--------------------------------------------------------------------------------
1. 本質：Windows 系統記錄所有軟硬體事件、使用者登入、安全警報的中央資料庫。
2. 實體檔案存放位置：
   C:\Windows\System32\winevt\Logs\*.evtx
3. 最核心的日誌類別：
   - Security (安全日誌)    : 稽核登入成功/失敗、權限變更、帳號建立 (滲透/防禦最看重)
   - System (系統日誌)      : 驅動載入、服務啟動失敗、系統崩潰
   - Application (應用程式) : 安裝的軟體或服務自身的執行錯誤/紀錄


[實務與滲透核心用途]
--------------------------------------------------------------------------------
1. 鑑識追蹤 (藍隊)：依賴「Event ID (事件編號)」快速過濾惡意活動 (如 4625 為登入失敗)。
2. 清理痕跡 (紅隊)：攻擊完成後利用 wevtutil 指令抹除事件紀錄。


[實務常用指令速查]
--------------------------------------------------------------------------------
1. 傳統指令工具：wevtutil (Cmd / PowerShell 皆可用)
   - 列出所有日誌名稱     : wevtutil el
   - 查詢特定日誌近期事件 : wevtutil qe Security /c:5 /rd:true /f:text
   - 匯出事件日誌成檔案   : wevtutil epl System C:\system_export.evtx
   - 清理/銷毀日誌 (紅隊) : wevtutil cl <日誌名稱> (例如: wevtutil cl Security)

2. PowerShell 現代指令：Get-WinEvent
   - 列出所有日誌與事件數 : Get-WinEvent -ListLog *
   - 查詢特定日誌最新 5 筆: Get-WinEvent -LogName 'Security' -MaxEvents 5
   - 依 EventID 篩選事件  : Get-WinEvent -FilterHashtable @{LogName='Security'; ID=4624}

================================================================================
Windows 網路情蒐、探測與 WinRM 遠端連線全章精華速查筆記
================================================================================

[第一階段：靶機本機網路情蒐 (Recon & Pivoting)]
--------------------------------------------------------------------------------
1. ipconfig /all
   - 用途：看所有網卡 IP、DNS、DHCP 資訊。
   - 滲透核心：尋找「雙宿主機 (Dual-Homed)」，若有兩張不同網段的網卡，可當跳板打入內網。

2. arp -a
   - 用途：查詢本機快取的 ARP 清單。
   - 滲透核心：直接偷看內網最近通訊過的存活主機 (如 Domain Controller、檔案伺服器)。

3. netstat -ano
   - 用途：列出本機所有開放的 Port 及對應的 Process PID。
   - 滲透核心：尋找只綁定 127.0.0.1 (Localhost) 的內部未對外服務，常用於本地提權。

4. route print
   - 用途：查看路由表，確認對外閘道與內網路由走向。


[第二階段：網路與服務連線探測 (PowerShell 原生探針)]
--------------------------------------------------------------------------------
1. Test-NetConnection -ComputerName <IP> -Port <Port號> (簡寫: tnc)
   - 用途：免裝任何工具，直接測試目標特定 Port 是否開放 (類似 Linux 的 nc / nmap 測單 Port)。
   - 範例：tnc 192.168.1.10 -Port 445

2. Test-WSMan -ComputerName <IP>
   - 用途：免登入直接測試遠端主機的 WinRM 服務是否存活與支援版本。


[第三階段：WinRM 遠端管理與拿 Shell (紅隊核心)]
--------------------------------------------------------------------------------
1. 核心觀念：
   - WinRM 是 Windows 原生遠端管理協定 (等同 Linux 的 SSH)。
   - 必背 Port：TCP 5985 (HTTP 明文 / 靶機最常見)、TCP 5986 (HTTPS 加密)。
   - 只要掃描發現 5985 開放，搭配帳號密碼或 NTLM Hash 即可直取 Shell。

2. 目標主機一鍵啟用指令：
   winrm quickconfig
   (自動啟動 WinRM 服務、設定開機自啟、防火牆自動放行 5985)

3. 遠端連線指令 (取得交互式 Shell)：
   - 從 Windows 連入目標 (PowerShell 原生)：
     Enter-PSSession -ComputerName <目標IP> -Credential <帳號>
   - 從 Kali Linux 連入目標 (打靶神器 evil-winrm)：
     evil-winrm -i <目標IP> -u <帳號> -p '<密碼>'
     evil-winrm -i <目標IP> -u <帳號> -H <NTLM_Hash>

================================================================================
PowerShell 腳本編寫與自動化模組 (Scripting & Modules) 精華筆記
================================================================================

[核心觀念]
--------------------------------------------------------------------------------
1. 本質：將日常重複的滲透指令 (如 IP、使用者清查、網域情蒐) 打包成自動化工具。
2. 核心副檔名 (重要觀念考點)：
   - .ps1  : PowerShell 一般腳本檔案 (直接執行的程式碼)
   - .psm1 : PowerShell 模組檔案 (Module，放置自定義 Function 函式庫)
   - .psd1 : 模組清單描述檔 (Manifest，存放模組版本、作者與相依性設定)


[常用基本語法]
--------------------------------------------------------------------------------
1. 註解語法：
   - 單行註解 : # 註解內容
   - 多行區塊 : <# 
                  多行註解內容 
                #>

2. 變數與字串格式化：
   - 變數宣告 : $變數名稱 = "內容" (如: $IP = ipconfig)
   - 取得電腦名: $env:ComputerName

3. 模組載入指令：
   Import-Module .\模組名稱.psm1
   (載入後即可直接在終端機呼叫模組內定義的 Function)

4. 結果寫入檔案 (產出偵察報表)：
   - 建立新檔案 : New-Item -Path .\recon.txt -ItemType File
   - 追加寫入內容: Add-Content -Path .\recon.txt -Value $變數

================================================================================
PowerShell 作用域 (Scope) 與模組進階管理精華筆記
================================================================================

[三大作用域層級 (Scope Levels - HTB 核心理論考點)]
--------------------------------------------------------------------------------
1. Global (全域) : 整個 PowerShell 會話生命週期皆有效，所有函式與別名均可存取。
2. Local (區域)  : 當前執行的操作區域 (預設範圍)，超出該區塊即失效。
3. Script (腳本) : 僅在特定腳本執行期間有效，避免腳本內的臨時變數污染全域環境。


[模組封裝與除錯指令]
--------------------------------------------------------------------------------
1. 匯出模組內的功能 (讓外部可以使用該 Function)：
   Export-ModuleMember -Function <函式名稱> -Variable <變數名稱>

2. 檢查目前系統已載入的模組清單：
   Get-Module

3. 查詢模組內建的說明文件 (Comment-based Help)：
   Get-Help <函式名稱>
   (範例: Get-Help Get-Recon)
