/ (根目錄 Root)
├── /bin     (基礎指令：ls, cat, bash)
├── /boot    (開機檔案：Linux 核心、GRUB)
├── /dev     (硬體裝置：磁碟、周邊裝置檔案)
├── /etc     (系統設定檔：passwd, shadow, crontab)
├── /home    (使用者家目錄：個人檔案與隱私配置)
├── /lib     (核心函式庫：.so 共享函式庫)
├── /media   (可卸除媒體：隨身碟自動掛載)
├── /mnt     (手動掛載點：管理員手動掛載磁碟)
├── /opt     (第三方選用軟體：非官方自編譯套件)
├── /proc    (虛擬行程資訊：記憶體與執行狀態)
├── /root    (超級管理員家目錄：root 專屬區)
├── /run     (開機運行狀態：PID、臨時執行檔)
├── /sbin    (系統管理指令：fdisk, reboot 等)
├── /sys     (系統硬體介面：核心與驅動資訊)
├── /tmp     (暫存檔案區：全域可讀寫暫存)
├── /usr     (共用系統資源：二級程式庫與工具)
└── /var     (變動資料目錄：log 日誌、www 網頁)

【Linux 核心求助指令速查清單】
==================================================

1. <指令> --help  或  <指令> -h
--------------------------------------------------
・功能：快速參數說明
・用途：忘記特定參數（如 -p、-v）時首選，直接印出簡要摘要。
・操作：直接顯示於終端機，不需離開。


2. man <指令>
---------------------------------------------- ----
・功能：完整官方手冊 (Manual)
・用途：詳細了解指令用法、完整參數定義與官方範例。
・操作：
    - 按「q」：退出手冊回到終端機
    - 按「/關鍵字」：搜尋手冊內容（按 n 跳下一個）
    - 按「Space 空白鍵」：向下翻一整頁


3. apropos <關鍵字>
--------------------------------------------------
・功能：關鍵字模糊反查
・用途：忘記指令全名，只記得功能或英文詞彙時搜尋所有手冊。
・範例：
    - apropos sudo     (找出所有管理員相關指令)
    - apropos routing  (找出所有網路路由工具)


4. whatis <指令>
--------------------------------------------------
・功能：一行極速簡介
・用途：遇到陌生指令，花 1 秒快速知道它是幹嘛的。
・範例：whatis tar


5. which <指令>
--------------------------------------------------
・功能：執行檔路徑定位
・用途：檢查指令安裝在哪個路徑，或確認靶機系統是否有安裝該工具。
・範例：which python3


6. whereis <指令>
--------------------------------------------------
・功能：全方位路徑定位
・用途：同時尋找指令的二進位執行檔、原始碼與 man 手冊位置。
・範例：whereis nmap


7. type <指令>
--------------------------------------------------
・功能：指令型態分析
・用途：判斷指令是內建程式 (builtin)、外部執行檔還是別名 (alias)。
・範例：type ls


==================================================
【滲透實戰提權技巧：man 指令】
==================================================
情境：若 sudo -l 顯示可免密碼執行 man (例如 sudo man ls)
提權步驟：
1. 輸入 sudo man ls 進入手冊畫面
2. 在畫面中直接輸入：!/bin/bash
3. 按 Enter 即可直接取得 root 最高權限 Shell！

==================================================
【Linux 系統資訊與枚舉指令速查清單2(HTB / eJPT)】
==============un====================================

一、 身分與權限確認（確認目前身分與特權）
--------------------------------------------------
1. whoami
   ・說明：顯示目前登入的使用者名稱。
   ・用途：拿到 Shell 第一秒執行，看是 www-data、一般使用者還是 root。

2. id
   ・說明：列出使用者的 UID、GID 及所屬的所有群組。
   ・實戰：確認是否在 sudo、docker、lxd、disk 等具備直接提權特權的群組。

3. who
   ・說明：顯示目前系統上有哪些使用者已登入。
   ・實戰：檢查是否有管理員或其他人在線上，避免操作被當場發現。


二、 系統環境與主機基本資訊（確認系統架構與路徑）
--------------------------------------------------
4. hostname
   ・說明：顯示或設定目前主機的名稱。
   ・實戰：確認當前靶機身分（例如 DEV-SRV、DC01），避免多台靶機時搞混。

5. uname -a
   ・說明：列印作業系統名稱、核心版本 (Kernel) 與硬體架構。
   ・實戰：拿印出的 Kernel 版本搜尋是否有已知的核心漏洞（如 Dirty COW）。

6. pwd
   ・說明：印出目前所在的工作目錄完整路徑。
   ・實戰：在盲注或無路徑提示的陽春 Shell 中確認自己停在哪個資料夾。

7. env
   ・說明：列印當前環境的所有環境變數。
   ・實戰：搜尋開發者遺留的敏感資訊，如 API Key、資料庫連線密碼、Token。


三、 網路連線與介面狀態（確認內網與通訊）
--------------------------------------------------
8. ifconfig  或  ip a (或 ip)
   ・說明：檢視或設定網路卡介面、IP 位址與子網遮罩。
   ・實戰：檢查是否有第二張內網網卡（如 10.x.x.x 或 192.168.x.x）供跳板滲透。

9. netstat -tuln  或  ss -tuln
   ・說明：顯示網路連線與通訊埠 (Port) 狀態。
   ・實戰：找出只綁定在 127.0.0.1 (Localhost) 的內部服務，進行本地提權突破。


四、 行程與檔案資源（檢查背景任務與硬體）
--------------------------------------------------
10. ps aux  (或 ps)
    ・說明：顯示系統當前執行中的所有行程狀態。
    ・實戰：檢查是否有以 root 權限跑在背景的自訂腳本、備份排程或可疑任務。

11. lsof -i
    ・說明：列出所有已被開啟的檔案與網路連線。
    ・實戰：檢查特定程序正在讀寫哪些敏感檔案或對外連線。

12. lsblk
    ・說明：列出所有塊設備（硬碟與分割區）。
    ・實戰：檢查是否有未掛載的磁碟分割區，常有舊資料或備份檔遺留。

13. lsusb
    ・說明：列出所有 USB 裝置。
    ・實戰：確認外接硬體、隨身碟或特定外設。

14. lspci
    ・說明：列出所有 PCI 匯流排裝置（如顯卡、網卡、RAID 卡等）。
    ・實戰：確認底層虛擬化環境或硬體規格。

【後滲透枚舉黃金四步（拿到 Shell 優先敲）】
==================================================
1. whoami && id       -> 確認我是誰、我有什麼群組權限
2. uname -a           -> 查內核版本看有沒有現成漏洞
3. ip a               -> 找內網跳板網段
4. netstat -tuln      -> 找綁定 127.0.0.1 的隱藏服務
